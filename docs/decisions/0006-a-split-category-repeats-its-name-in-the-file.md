# 0006: A split category is written as its name repeated, side by side

Round 4, R17 ("Any category, aside form Midterm and Final (that should ALWAYS BE 2.0 and
3.0), can be broken into smaller categories." and "Any separtion should always be done
like the example (X.0 - X.9).").

In the context of saving a category split into parts (R17), where every class file and
saved class has been three lines (names, weights, grades) since round 1, and where the
R17 example shows a row of numbers (`1.0 1.1 2.0 3.0 4.0`) above the names,
facing the question of how the file says which items are parts of one category,
we decided to write a split category as its name repeated side by side, once per part,
each with its own weight and grade (`homework / homework / midterm / final / attendance`),
with capitals ignored, and to work the numbers out from the order (homework 1, midterm 2,
final 3, attendance 4, others 5, 6, ...), showing the numbers row on the screen only,
and neglected adding a fourth line of numbers above the names, as on the screen, and also
neglected writing the number into each name (`homework 1.0 / homework 1.1 / ...`),
to achieve files that keep the three-line layout, so older saved classes and the GPA
across classes (R14) keep working unchanged, that stay easy to write and edit by hand
(R11), and numbers that can never disagree with the order of the names, since they are not
stored,
accepting that a name can no longer be used in two places (`project / quiz / project` is
now a file problem, explained with its line number), that `homework / hw` is not a split
because the spellings differ, and that three new file rules had to be added: midterm or
final repeated, more than 10 parts, and a name in two places.

Decided by the student in the round 4 questions, from the options above.
