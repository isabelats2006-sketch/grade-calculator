# 0002: Quit moves to the end of the menu

Round 2, R12 and R13 (delete and rename from the open-class menu).

In the context of adding "Rename this class" and "Delete this class" to the menu of an open
class, which in round 1 was 1) Change a grade, 2) Change the goal, 3) Quit,
facing the choice between keeping Quit at 3 (so nothing a user already learned changes) and
keeping Quit last (where menus usually put it),
we decided to number the menu 1) Change a grade, 2) Change the goal, 3) Rename this class,
4) Delete this class, 5) Quit,
and neglected keeping 3) Quit with rename and delete as 4 and 5, and neglected using letters
(r, d) in this menu like in the saved-class list,
to achieve a menu that reads in a natural order, with the two class-wide actions together
and Quit at the end, as user friendly as R6 asks,
accepting that someone used to typing 3 to quit now gets the rename question (Enter keeps the
name, and `q` still quits at any question), and that 13 round 1 tests had their last answer
changed from 3 to 5.
